This repository contains the following files: 
* Detailed codebooks for all three parts of the study
* Supplementary Online Material (SOM) including information on the data collection periods, deviations from the preregistration, description of the pretest to select personality state items, descriptive statistics of the key constructs assessed in the ESM part, and visualizations of interfaces of selected item formats
* Additional materials, including the information provided before the start of the ESM part and the individualized feedback participants received at the end of the study
* Functions used to analyze and feedback participants' their results during the study
